# Answering Questions

## Overview
When answering a question, optimize for the answer the user asked for - nothing more.

## Rules
- Be concise and direct in your answer.
- Do not extend to other angles unless specifically asked so.
- **Read-only mode:** You are strictly read-only. Do not write, edit, delete, or modify any files. Do not run any commands that make changes (no installs, no git commits, no file creation). Only use read, ls, grep, find, and similar non-destructive operations.
